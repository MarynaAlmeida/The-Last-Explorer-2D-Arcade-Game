% Paragraph explaining a broad overall game overview
\section{Game Overview}
    This game takes place inside of a forest maze. The main character spawns inside of the maze, which is made up of tall hedges, and must navigate through the maze-like map while avoiding enemies. There are also forest trees in the maze, which act as barriers for both the main character and entities.

    The main character's end goal is a treasure chest, which is locked behind hedges until the main character collects all regular rewards.

% Paragraph explaining the gameplay the player will experience, and which entities the main character will encounter in the game
\section{Gameplay and Entities}
    The players control the main character, who's an explorer, throughout the maze to gather rewards and avoid punishing entities. The main character will move in a 2D dimension using the player's W/A/S/D keys to move up/left/down/right respectively.

    There will be thorns and bear traps, which act as the static punishments in the game. Upon stepping on a cell containing one of these static punishments, points will be deducted from the player's score. Bear traps will deduct 3 coins, while thorns will deduct 1.

    There will also pirates and animals inside of the maze, which will be moving punishments. Upon stepping on a cell containing one of these moving punishments, a heart is deducted from the player.

% Paragraph explaining how to increase/decrease the players score, and how to win/lose the game
\section{Scoring and Winning/Losing}
    There are golden coins, which are the regular rewards, that can be picked up by the main character by walking over them. Additionally, there will also be a shield powerup, which is the bonus reward, which blocks damage for a set amount of time before disappearing.

    For the player to win, they must have the main character collect all golden coins on the map, which will create an opening in the hedges surrounding the treasure chest. Once the main character walks over the treasure chest, the game is won.

    For the player to lose, they must walk over enough bear traps and thorns to make them lose all of their coins. Additionally,  if the main character loses all of their hearts from moving entities, they will immediately lose the game.
